1 Komponen Materi

SUMPRODUCT Dasar

Mengalikan range1[i] × range2[i] lalu menjumlahkan semua hasil — tanpa kolom bantu.

Array

Array adalah sekumpulan data yang disusun dalam sebuah daftar (satu kolom/baris) atau sebuah tabel (banyak kolom dan baris)

Array Legacy Filter ( * )

Menggabungkan beberapa kriteria dengan operator perkalian (*) untuk filtering multi-kriteria.

Rata-rata Tertimbang

Kombinasi SUMPRODUCT dan SUM untuk menghitung weighted average pada persediaan.

2 Rumus & Alat

SUMPRODUCT Dasar

=SUMPRODUCT(Range1, Range2)

Multi-Criteria Array

=SUMPRODUCT((kriteria1)*(kriteria2)*(...)*(range_nilai))

Weighted Average

=SUMPRODUCT(Range_Stok, Range_HPP) / SUM(Range_Stok)

3 Optimasi Tampilan
