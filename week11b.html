1 Komponen Materi

Time-Series Forecasting

Menggunakan data historis untuk memprediksi nilai masa depan dengan fungsi FORECAST atau TREND, penting untuk perencanaan anggaran.

Korelasi (CORREL)

Mengukur kekuatan hubungan linier antara biaya iklan dan unit terjual. Nilai mendekati 1 menunjukkan hubungan positif kuat.

Analysis ToolPak Regression

Add-in Excel untuk analisis regresi mendalam, menghasilkan output seperti R-Square, P-Value, dan koefisien regresi.

Scatter Chart & Trendline

Visualisasi data dengan garis tren linier untuk menampilkan rumus prediksi (y = mx + c) secara grafis.

2 Rumus & Alat

FORECAST (Prediksi Linier)

=FORECAST(x_target, range_y_known, range_x_known)

CORREL (Korelasi)

=CORREL(range_x, range_y)

TREND (Array)

=TREND(range_y_known, range_x_known, x_new)

Analysis ToolPak

Data → Data Analysis → Regression

3 Interpretasi Output

R-Square > 0.70 = Model Kuat

P-Value < 0.05 = Signifikan

y = mx + c = Persamaan Prediksi

Contoh Formula

=FORECAST(25, B2:B25, A2:A25) → prediksi penjualan bulan ke-25

=CORREL(B2:B16, C2:C16) → korelasi biaya iklan vs unit terjual
