W9

Kasus A

Target Profit (Goal Seek)

Cari berapa unit yang harus terjual agar tercapai profit bersih Rp 1.000.000.000.

Kasus B

Sensitivitas 1-Variabel

Data Table satu-variabel untuk variasi harga jual (+5%, +10%, +15%).

Kasus C

Sensitivitas 2-Variabel

Data Table dua-variabel: Harga Jual vs Biaya Produksi.

Kasus D

Rekomendasi Bisnis

Simpulkan skenario paling aman berdasarkan tabel sensitivitas.

1 Komponen Materi

Target Seeking

Teknik mencari input yang menghasilkan target finansial tertentu (Goal Seek).

Sensitivity Analysis

Mengukur dampak perubahan variabel kunci terhadap profit.

Scenario Modeling

Membangun beberapa skenario pasar untuk prediksi hasil.

2 Rumus & Alat

Goal Seek

Menetapkan target sel dan mengubah sel input untuk mencapai nilai target.

Data Table (1-var / 2-var)

Ringkasan hasil untuk banyak variasi sekaligus.

Referensi Sel

Gunakan referensi absolut ($) saat diperlukan agar Data Table bekerja otomatis.

3 Optimasi Tampilan

Data Table Sederhana

Goal Seek Demo

Format Persen & Mata Uang

Referensi Absolut ($)

Rincian Aktivitas (90 Menit)

30 Menit - Teori & Demo

  1. Penjelasan Goal Seek dan Data Table.
  2. Demo mencari Unit Sold untuk target profit (Goal Seek).
  3. Demo Data Table satu-variabel untuk variasi harga.

60 Menit - Praktik Mandiri

  1. Kasus A: Goal Seek target profit Rp 1.000.000.000.
  2. Kasus B: Data Table 1-variabel (+5%, +10%, +15%).
  3. Kasus C: Data Table 2-variabel (Harga vs Biaya).
  4. Kasus D: Rekomendasi berdasarkan sensitivitas.
