1 Komponen Materi

Korelasi (r)

Mengukur kekuatan dan arah hubungan linier antara dua variabel. Nilai mendekati 1 atau -1 menunjukkan hubungan kuat.

Regresi Linier

Membangun model prediktif y = mx + c untuk memperkirakan variabel dependen berdasarkan variabel independen.

Analysis ToolPak

Add-in Excel untuk analisis statistik mendalam, termasuk regresi dan korelasi, menghasilkan output seperti P-Value dan R-Square.

Forecasting

Menggunakan data historis untuk meramalkan nilai masa depan dengan fungsi FORECAST.ETS atau TREND.

2 Rumus & Alat

Korelasi

=CORREL(range_variabel1, range_variabel2)

Regresi (Prediksi)

=FORECAST(x_target, range_y_known, range_x_known)

Forecast ETS

=FORECAST.ETS(target_date, range_nilai, range_tanggal, seasonal_pattern)

Analysis ToolPak

Data → Data Analysis → Regression

3 Interpretasi Output

P-Value < 0.05 = Signifikan

R-Square mendekati 1 = Model Kuat

Multiple R = Korelasi

Contoh Formula

=CORREL(B2:B11, C2:C11) → korelasi iklan vs penjualan

=FORECAST(7000000, D2:D11, C2:C11) → ramalan penjualan jika biaya pemasaran 7 juta
